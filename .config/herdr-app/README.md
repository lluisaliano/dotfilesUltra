# herdr-luxor

My [Herdr](https://herdr.dev) setup: the `luxor-layout` layout, its mods, keys, settings and themes.
It is the `~/.config/herdr-app` folder without Herdr's shipped files and runtime state (see `.gitignore`).

## Install

```sh
git clone https://github.com/lluisaliano/herdr-luxor.git ~/.config/herdr-app
```

Then switch to the layout with `herdr-app do layout.switch '{"name":"luxor-layout"}'`.

Some mods come from other people's repos (`linear`, `servers`, `pr-review-assist`,
`herdr-open-with-zed`) and carry local changes. Their licenses are in their folders.
